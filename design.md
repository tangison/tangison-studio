# Design — The Tangison Studio

A locked design system for studio.tangison.com. Every page redesign reads this file
before emitting code. Do not regenerate per page — extend or amend this file when
the system needs to grow.

Hallmark stamp: `/* Hallmark · genre: editorial-studio · macrostructure: Portfolio Grid / Long Document · design-system: design.md · designed-as-app */`

## Genre

editorial (studio / agency work-led), held to the Collins bar — wearecollins.com is
the named reference for craft level, not for its visual identity.

## Macrostructure family

- Marketing / gallery pages (home, /cases): **Portfolio Grid** — tagline head
  (the studio slogan, hero copy only, never location or positioning text),
  inline studio film tile below the copy, trust layer of real client names,
  image-led grid, no display-heavy intro. One featured full-width tile,
  tight 2-col grid below.
- Content pages (/blog/[slug], /about, /services, /audit): **Long Document** —
  dark ink surface, single reading column (65–68ch), hanging section heads,
  typographic hierarchy.
- Case study pages (/cases/[slug]): **Split Studio** — dark ink surface, hero art,
  two-col meta header, prose body, craft grid.
- Utility pages (/search): Long Document dark, functional, no hero art.

## Theme

Two route themes, flipped by `.theme-ink` on the page wrapper.

- `--paper` #F6F4EF (bone), `--paper-raise` #FEFDFB (warm raise)
- `--ink` #111315 (Atlantic black), `--ink-muted` ink @ 64%, `--ink-faint` ink @ 40%
- `--line` ink @ 8% (faded hairline), `--line-strong` ink @ 18%
- `--teal` #2CB5B4 (Signal Teal, dark theme #3ECBCA) — the ONLY accent, ≤ 5% per viewport
- Ink theme: paper #0C1014, raise #14181D, ink #F6F4EF, line bone @ 12% / 26%

No gradients except photo scrims. No pure #000/#FFF. Neutrals carry no extra hue
beyond the existing warm bone.

## Typography

- Display: **Poppins** (local woff2) — weight 600 headlines / 700 hero. Tracking
  -0.02em to -0.03em. Roman only, never italic. (User-mandated face.)
- Body: **Satoshi** 400, 16px floor, 1.6–1.75 leading.
- Outlier: **JetBrains Mono** 400 — metadata slots only (case category · year,
  dates, coordinates). Max two roles per page. Mono eyebrows as section labels
  are REMOVED (eyebrow default-off).
- Type scale (bigger, bolder than v2): h1 clamp(2.75rem, 6.5vw, 5.25rem) w700;
  h2 clamp(1.9rem, 3.6vw, 3rem) w600; h3 clamp(1.3rem, 2.2vw, 1.6rem) w600.
  Hero ≤ 5.25rem. Display line-height 1.05–1.12.

## Spacing

Existing Tailwind spacing + section rhythm: py 24/32 top-heavy sections, uneven
by design. One break-out or asymmetry per page minimum.

## Motion

- Easings: `--ease-primary` cubic-bezier(0.16, 1, 0.3, 1) (expo-out). No bounce,
  no elastic, no `ease` default, no linear except loaders.
- Durations: micro 150ms / short 300ms / long 500–900ms (gallery zoom 1.1s).
- Reveal: IntersectionObserver reveal-once, fade-rise only. ONE orchestrated
  page-load entrance (hero stagger). Below-fold content settles without stagger
  cascades.
- Wordmark: "The Tangison Studio" — staggered word fade-rise on first paint,
  CSS-only, reduced-motion collapses to opacity.
- Reduced motion: all spatial motion collapses to ≤150ms opacity crossfade.

## Microinteractions stance

- Buttons: background-color shift only, 150ms expo-out. No hover translate+scale
  stacks on buttons. Focus rings appear instantly (outline, never transitioned).
- Gallery tiles: image zoom-in 1.07 + brightness 1.03 on hover/focus (1.1s
  expo-out) — the single signature interaction, identical everywhere.
- Links: underline grows from left, 300ms.

## CTA voice

- Primary: pill (999px radius), solid ink fill, paper text, plain label only —
  no icon inside, no nested buttons, no shadow on the button. Labels are verb
  first: "Start a project", "See the work".
- Secondary: pill, hairline outline (line-strong), ink text, transparent bg.
- Ghost/tertiary: plain typographic link with growing underline.

## Imagery

- **Hero film (user-mandated exception, v3)**: the studio painting film runs
  INLINE after the hero tagline (never a full-bleed background, never before
  the copy). 752x470 (16:10), muted + loop + playsinline, poster-first
  (16KB WebP, preloaded), playback starts on intersection only, ~510KB mp4
  fetched lazily. The bottom-right watermark zone is delogo'd and the corner
  precision-cropped; the filename is versioned (hero-v3) to bust caches.
- Every page hero carries ONE minimal oil painting element (Pollinations,
  pinned seeds), single subject, light bone ground, biased off-centre — light
  and lean. Case covers and article covers keep their own art.
- Light paper: imagery sits on rounded-[20px] tiles with ONE soft radiating
  shadow `0 24px 60px -24px rgba(12,16,20,0.18)` (the "radiating shadow" rule).
- Dark ink: NO box shadows (no glow on dark) — elevation by lighter surface.
- Logo/wordmark: always the real Tangison SVG or typographic wordmark. Never
  regenerated by an image model.

## Borders

Faded, not generic: hairlines at ink 8% (light) / bone 12% (dark). Section
dividers prefer negative space; where a rule is needed it fades at the edges
(gradient rule), never a full-width hard box border around prose blocks.

## What pages MUST share

- The wordmark "The Tangison Studio" (animated in the header).
- Teal accent, ≤ 5% footprint.
- Poppins display + Satoshi body.
- The pill CTA voice.
- Location string: Windhoek West, Namibia.

## What pages MAY differ on

- Light (gallery: home, /cases, /contact) vs ink (text: /about, /services,
  /audit, /blog, /search, /cases/[slug], /blog/[slug]).
- Hero art subject per page.
- Macrostructure within the declared family.

## Performance contract

Sub-500KB page transfer (3G). Hero film allowed as the one documented
exception: inline, lazy, poster-first, so it never counts against first paint
or LCP. WebP imagery, lazy below fold, priority on LCP art. Three font
families max, subset woff2, swap display.
