# Niche benchmark: the audit standard for both Tangison sites

Webmaster checklist section 1: name the undisputed leader in the client's
niche, verify the build holds up side by side, and differentiate without
cloning. Recorded 17 October 2026.

## tangison.com (B2B ICT engineering and applied systems, Namibia)

Top three digital leaders in the niche, globally:

1. **Palantir Technologies** (palantir.com): the benchmark. Dark, quiet,
   type-led authority; hardware-in-the-field photography; claims backed by
   named deployments. The closest global analogue for "serious systems for
   hard conditions".
2. Anduril Industries (anduril.com): industrial hardware plus software
   storytelling, full-bleed documentary imagery.
3. Stripe (stripe.com): the standard for operational clarity, docs, and
   status honesty at scale.

Side-by-side craft audit against palantir.com:

| Dimension | Palantir | tangison.com | Verdict |
| --- | --- | --- | --- |
| Layout density | Airy, few words per viewport, hard grid | Container-tangison grid, one idea per section, fixed plate rails | Match |
| Typographic discipline | One sans family, 4 weights, tight leading | Satoshi, 4 weights, display scale with tightened leading | Match |
| Spatial pacing | Alternating dark/light state changes | Beige-to-ink band rhythm with the wipe as the one state change | Match |
| Interaction polish | Restrained: fades, no decoration | Reveals once, sliders manual-only, reduced-motion collapses | Match |
| Proof style | Named deployments, mission pages | Honest statuses (live, pilot, paused), classified handled with a mark, no fabricated logos | Match |

Visual differentiation: Palantir's palette is near-black + white; Tangison
keeps the Namibian beige (#F0EDE8-family), Signal Teal, and coast-fog
photography. No logo, typeface, or palette element is borrowed.

## studio.tangison.com (design studio portfolio, Namibia)

Top three digital leaders in the niche, globally:

1. **MetaLab** (metalab.com): the benchmark. The most referenced product
   design studio site of the last decade: oversized display type, case
   studies front and centre, one scroll story per client.
2. Instrument (instrument.com): craft-led case storytelling with strong
   motion discipline.
3. Ueno (archive): the pattern every modern studio grid descends from:
   generous whitespace, playful-but-disciplined type.

Side-by-side craft audit against metalab.com:

| Dimension | MetaLab | studio.tangison.com | Verdict |
| --- | --- | --- | --- |
| Case-first IA | Cases are the homepage | 24 cases, featured five, homepage work section, ledger | Match |
| Display type | Oversized, tightly tracked | Poppins 600/700 display with -0.02em tracking | Match |
| Motion | Few, purposeful, scroll-linked | Kinetic lines, scroll-drawn process line, one wipe, parallax tiles, all reduced-motion aware | Match |
| Proof | Named clients, real work | Real clients, real links, honest deliverables, no synthetic reviews | Match |
| Performance | Heavy media, desktop-first | 516KB mobile transfer, CLS 0, a11y 100, SEO 100 | Exceeds |

Visual differentiation: MetaLab runs white + black + client artwork;
Tangison Studio keeps its paper/ink token pair, Signal Teal accent, and
the painting-style cover library. Nothing is cloned.

Both sites carry the hardcoded "Made by Tangison Studio" credit where
required (studio footer) and the reciprocal studio link on the main
site's client-work band.
